    How this dashboard gets its data

    The page asks a Node.js and Express backend for the tasks using fetch(). No task information is written inside the page.

    1. Intern Dashboard
    2. JavaScript fetch()
    3. REST API (Node.js + Express)
    4. Task data (tasks.json)
    MethodEndpointPurpose
    GET/api/tasksGet all tasks
    GET/api/tasks/:idGet one task
    PUT/api/tasks/:idUpdate a task's status. Body: {"status":"completed"}
    GET/api/healthCheck that the backend is running
    POST/api/resetReset all tasks to the starting sample
